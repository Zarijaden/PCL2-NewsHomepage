## 更改

### 用户界面

- macOS 现已再次提供“独占全屏”选项。
- macOS 的视频设置中新增“菜单栏/Dock 显示”选项，用于控制在全屏时，将鼠标移至屏幕边缘能否显示 macOS 菜单栏和 Dock。
- 启用独占全屏时，鼠标光标现会限制在窗口内。

## 技术性更改

- 数据包版本现在为 `119.0`。
- 资源包版本现在为 `97.1`。

## 数据包版本 119.0

- `minecraft:number_provider` 和 `minecraft:number_provider_type` 注册表已拆分为整数计算注册表（`minecraft:context_int_provider`、`minecraft:context_int_provider_type`）和浮点计算注册表（`minecraft:context_float_provider`、`minecraft:context_float_provider_type`）。

### 数值提供器

数值提供器类型和值已拆分至 `minecraft:context_int_provider` 和 `minecraft:context_float_provider` 两个注册表，以避免混用浮点和整数运算时意外损失精度和范围。

注意：这些新类型不要与已有的 `minecraft:int_provider_type` 和 `minecraft:float_provider_type` 混淆；后两者是不依赖上下文的提供器，主要用于世界生成。

### 整数数值提供器

- 新增 `minecraft:context_int_provider` 注册表。
- 所有计算均使用 32 位整数进行。
- 产生无效值（如除以零）的计算结果未定义。
- 格式：
  - `type`：来自 `minecraft:context_int_provider_type` 注册表的命名空间 ID。
  - `<type-specific fields>`：类型专用字段。

#### 新增 `minecraft:abs`

- 返回 `input` 的绝对值。
- 若最终结果无法容纳于 32 位整数，计算将取消。
- 字段：
	- `input`：内联值或 `minecraft:context_int_provider` 类型的命名空间 ID。

#### 新增 `minecraft:avg`

- 计算多个整数提供器并返回结果的算术平均值；除法向 `0` 取整。
- 字段：
	- `inputs`：内联值、单个命名空间 ID、命名空间 ID 列表、内联值列表，或带 `#` 前缀的 `minecraft:context_int_provider` 类型标签 ID；至少需要一个值。

#### 新增 `minecraft:binomial`

- 以成功概率 `p` 进行 `n` 次随机抛硬币，并返回成功次数。
- 字段：
	- `n`：抛硬币次数，内联值或 `minecraft:context_int_provider` 类型 ID；`p`：单次成功概率（`[0.0, 1.0]`），内联值或 `minecraft:context_float_provider` 类型 ID。

#### 新增 `minecraft:conditional`

- 条件满足时返回 `on_true`，否则返回 `on_false`。
- 字段：
	- `condition`：内联值或 `minecraft:predicate` 类型 ID；`on_true`：条件满足时执行的内联值或 `minecraft:context_int_provider` 类型 ID；`on_false`：可选内联值或对应类型 ID，省略时默认为常量 `0`。

#### 新增 `minecraft:constant`

- 返回常量值。
- 字段：
	- `value`：整数。
- 也可写为纯数字内联形式（`foo: 1` 等同于 `foo: {type:"minecraft:constant",value:1}`）。

#### 新增 `minecraft:sub`

- 返回 `left` 减 `right`；若最终结果无法容纳于 32 位整数，计算将取消。
- 字段：
	- `left`、`right`：内联值或 `minecraft:context_int_provider` 类型 ID。

#### 新增 `minecraft:from_float`

- 计算浮点提供器并转换为整数值；非整数值会截断（向零取整）。
- 无法容纳于 32 位整数的值（包括 `NaN`）视为错误，并会取消计算。
- 字段：
	- `input`：内联值或 `minecraft:context_float_provider` 类型 ID。

#### 新增 `minecraft:max` / `minecraft:min`

- 分别计算多个整数提供器并返回最大值/最小值。
- 字段：
	- `inputs`：内联值、单个命名空间 ID、命名空间 ID 列表、内联值列表，或带 `#` 前缀的 `minecraft:context_int_provider` 类型标签 ID；至少需要一个值。

#### 新增 `minecraft:mod`

- 返回 `left` 除以 `right` 的余数，使用截断整数除法（向零取整）。
- 除以零视为错误，并会取消计算。
- 字段：
	- `left`、`right`：内联值或 `minecraft:context_int_provider` 类型 ID。

#### 新增 `minecraft:floor_mod`

- 返回 `left` 除以 `right` 的余数，使用向下取整的整数除法（向负无穷取整）。
- 除以零视为错误，并会取消计算。
- 字段：
	- `left`、`right`：内联值或 `minecraft:context_int_provider` 类型 ID。

#### 新增 `minecraft:environment_attribute`

- 获取并提供环境属性（`minecraft:environment_attribute`）的值。
- 字段：
	- `attribute`：要获取的环境属性 ID（必须可表示为 `int`）。

#### 新增 `minecraft:negate`

- 返回 `input` 的相反数；若最终结果无法容纳于 32 位整数，计算将取消。
- 字段：
	- `input`：内联值或 `minecraft:context_int_provider` 类型 ID。

#### 新增 `minecraft:number_dispatcher`

- 返回第一个条件满足的 case；若没有满足项，则返回 `default`。
- 字段：
	- `cases`：按分发器尝试顺序排列的 case 列表，每项含 `condition`（内联值或 `minecraft:predicate` 类型 ID）和 `value`（条件满足时执行的内联值或 `minecraft:context_int_provider` 类型 ID）；`default`：可选内联值或对应类型 ID，省略时默认为常量 `0`。

#### 新增 `minecraft:pow`

- 返回 `base` 的 `exponent` 次幂。
- 指数为负、底数与指数均为零，或最终结果无法容纳于 32 位整数时，计算将取消。
- 字段：
	- `base`、`exponent`：内联值或 `minecraft:context_int_provider` 类型 ID。

#### 新增 `minecraft:mul`

- 计算多个整数提供器并返回结果之积；若最终结果无法容纳于 32 位整数，计算将取消。
- 字段：
	- `inputs`：内联值、单个命名空间 ID、命名空间 ID 列表、内联值列表，或带 `#` 前缀的 `minecraft:context_int_provider` 类型标签 ID；至少需要一个值。

#### 新增 `minecraft:div`

- 返回 `left` 除以 `right` 的结果，使用截断整数除法（向零取整）。
- 除以零视为错误，并会取消计算。
- 字段：
	- `left`、`right`：内联值或 `minecraft:context_int_provider` 类型 ID。

#### 新增 `minecraft:floor_div`

- 返回 `left` 除以 `right` 的结果，使用向下取整的整数除法（向负无穷取整）。
- 除以零或最终结果无法容纳于 32 位整数时，计算将取消。
- 字段：
	- `left`、`right`：内联值或 `minecraft:context_int_provider` 类型 ID。

#### 新增 `minecraft:score`

- 返回选定目标的分数；若不存在分数，返回 `fallback` 的值。
- 字段：
	- `score`：计分板目标名称；`target`：分数持有者（格式与旧版数值提供器相同）；`fallback`：可选内联值或 `minecraft:context_int_provider` 类型 ID，默认 `0`。

#### 新增 `minecraft:storage`

- 从命令存储中返回整数值。
- 若值不存在、不是数字，或路径返回多个值，则返回 `fallback`。非整数数值 NBT 值的转换结果未定义。
- 字段：
	- `storage`：命令存储的命名空间 ID；`path`：NBT 路径；`fallback`：可选内联值或 `minecraft:context_int_provider` 类型 ID，默认 `0`。

#### 新增 `minecraft:add`

- 计算多个整数提供器并返回结果之和；若最终结果无法容纳于 32 位整数，计算将取消。
- 字段：
	- `inputs`：内联值、单个命名空间 ID、命名空间 ID 列表、内联值列表，或带 `#` 前缀的 `minecraft:context_int_provider` 类型标签 ID；至少需要一个值。

#### 新增 `minecraft:uniform`

- 从闭区间中随机选取一个整数。
- 字段：
	- `min`、`max`：含端点的最小值和最大值，内联值或 `minecraft:context_int_provider` 类型 ID。

#### 新增 `minecraft:weighted_list`

- 从加权数值提供器分布中返回一个值。
- 字段：
	- `distribution`：对象列表；每项含 `data`（内联值或 `minecraft:context_int_provider` 类型 ID）及 `weight`（正整数）。

### 浮点数值提供器

- 新增 `minecraft:context_float_provider` 注册表。
- 所有计算均使用单精度浮点数（float）进行。
- 产生 `NaN` 或无穷大的计算结果未定义。
- 格式：`type` 为来自 `minecraft:context_float_provider_type` 注册表的命名空间 ID，另加类型专用字段。

#### 新增原版浮点数值提供器

- `minecraft:cooking/speed_default`：返回烹饪燃料的默认速度倍率。
- `minecraft:cooking/normal_speed_multiplier`：返回在普通熔炉中使用烹饪燃料时的速度倍率。
- `minecraft:cooking/fast_speed_multiplier`：返回在匹配 `block/fast_cooking` 谓词的方块中使用烹饪燃料时的速度倍率。
- `minecraft:brewing/speed_default`：返回酿造燃料的默认速度倍率。

#### 新增 `minecraft:abs`、`minecraft:avg`、`minecraft:sub`、`minecraft:max`、`minecraft:min`、`minecraft:mod`、`minecraft:negate`、`minecraft:pow`、`minecraft:mul`、`minecraft:div`、`minecraft:add`

- 这些浮点变体分别返回绝对值、算术平均值、差、最大值、最小值、余数、相反数、幂、乘积、商和总和。
- `abs`、`sub`、`mod`、`negate`、`pow`、`div` 的字段为相应的 `input`，或 `left` 与 `right`，或 `base` 与 `exponent`；每个字段均为内联值或 `minecraft:context_float_provider` 类型 ID。
- `avg`、`max`、`min`、`mul`、`add` 的 `inputs` 可为内联值、单个命名空间 ID、命名空间 ID 列表、内联值列表，或带 `#` 前缀的 `minecraft:context_float_provider` 类型标签 ID，并至少需要一个值。

#### 新增 `minecraft:ceil`

- 返回 `input` 的向上取整值（向正无穷取整）。
- 字段：
	- `input`：内联值或 `minecraft:context_float_provider` 类型 ID。

#### 新增 `minecraft:conditional`

- 条件满足时返回 `on_true`，否则返回 `on_false`。
- 字段：
	- `conditions`：内联值或 `minecraft:predicate` 类型 ID；`on_true`：条件满足时执行的内联值或 `minecraft:context_float_provider` 类型 ID；`on_false`：可选内联值或对应类型 ID，省略时默认常量 `0.0`。

#### 新增 `minecraft:constant`

- 返回常量值。
- 字段：
	- `value`：浮点数。
- 也可写为纯数字内联形式（`foo: 1.0` 等同于 `foo: {type:"minecraft:constant",value:1.0}`）。

#### 新增 `minecraft:cos`

- 分别返回 `input` 的余弦值。
- 字段：
	- 
  - `input`：以弧度为单位的参数，内联值或 `minecraft:context_float_provider` 类型 ID。

#### 新增 `minecraft:enchantment_level`

- 计算基于附魔等级（`minecraft:enchantment_level_based_value_type`）的参数。
- 字段：
	- `amount`：根据附魔等级给出值的等级值。

#### 新增 `minecraft:environment_attribute`

#### 新增 `minecraft:floor`

#### 新增 `minecraft:from_int`

#### 修改了 `minecraft:set_damage`

- `damage` 字段现在接受内联值或 `minecraft:context_float_provider` 类型的命名空间 ID。

#### 修改了 `minecraft:set_ominous_bottle_amplifier`

- `amplifier` 字段现在接受内联值或 `minecraft:context_int_provider` 类型的命名空间 ID。

#### 修改了 `minecraft:set_random_dyes`

- `number_of_dyes` 字段现在接受内联值或 `minecraft:context_int_provider` 类型的命名空间 ID。

#### 修改了 `minecraft:set_stew_effect`

- `effects` 列表元素中的 `duration` 字段现在接受内联值或 `minecraft:context_int_provider` 类型的命名空间 ID。

### 谓词

#### 修改了 `minecraft:random_chance`

- `chance` 字段现在接受内联值或 `minecraft:context_float_provider` 类型的命名空间 ID。

#### 移除了 `minecraft:value_check`

- 此条件已拆分为整数和浮点变体。

#### 新增 `minecraft:int_value_check`

- 检查数值是否处于某个范围内。
- 字段：
	- 
  - `value`：内联值或 `minecraft:context_int_provider` 类型的命名空间 ID。
  - `test`：以下之一：内联值（包括单个整数）或 `minecraft:context_int_provider` 类型的命名空间 ID，用于测试 `value` 结果是否相等；或包含 `min`、`max` 的对象（均为可选内联值或对应类型 ID），用于测试 `value` 是否在两者之间（含端点）。

#### 新增 `minecraft:float_value_check`

- 检查数值是否处于某个范围内。
- 字段：
	- 
  - `value`：内联值或 `minecraft:context_float_provider` 类型的命名空间 ID。
  - `test`：以下之一：内联值（包括单个浮点数）或 `minecraft:context_float_provider` 类型的命名空间 ID，用于测试 `value` 结果是否相等；或包含 `min`、`max` 的对象（均为可选内联值或对应类型 ID），用于测试 `value` 是否在两者之间（含端点）。

#### 修改了 `minecraft:time_check`

- `value` 结构内的 `min` 和 `max` 字段现在接受内联值或 `minecraft:context_int_provider` 类型的命名空间 ID。
- `value` 字段本身现在也接受内联值或 `minecraft:context_int_provider` 类型的命名空间 ID（此前只允许整数）。

#### 修改了 `minecraft:entity_scores`

- `scores` 映射的值内 `min` 和 `max` 字段现在接受内联值或 `minecraft:context_int_provider` 类型的命名空间 ID。
- `scores` 字段本身现在也接受内联值或 `minecraft:context_int_provider` 类型的命名空间 ID（此前只允许整数）。

### 配方

#### 烹饪配方

- 所有烹饪配方的 `cookingtime` 字段不再可选。
- 自定义烟熏炉和高炉配方应相应更新，将 `cookingtime` 设为原值的两倍。
- 若自定义烹饪配方此前依赖默认的 `cookingtime`，可设为 `200` 以维持相同耗时。

### 世界生成

#### 方块状态提供器

方块状态提供器现可在注册表 `worldgen/block_state_provider` 中定义为独立类型，并可在要求方块状态提供器的字段中使用命名空间字符串引用。

内联方块状态定义现可作为提供该状态的 `minecraft:simple` 方块状态提供器的简写。方块状态必须是包含字段的对象形式，不允许使用方块 ID 简写。

##### 重命名提供器类型

下列提供器类型已被重命名：

- `minecraft:dual_noise_provider` → `minecraft:dual_noise`
- `minecraft:noise_provider` → `minecraft:noise`
- `minecraft:noise_threshold_provider` → `minecraft:noise_threshold`
- `minecraft:randomized_int_state_provider` → `minecraft:randomized_int`
- `minecraft:rule_based_state_provider` → `minecraft:rule_based`
- `minecraft:simple_state_provider` → `minecraft:simple`
- `minecraft:weighted_state_provider` → `minecraft:weighted`
- `minecraft:random_block_provider` → `minecraft:random_block`
- `minecraft:rotated_block_provider` → `minecraft:rotated`

##### 修改了 `minecraft:rule_based`：

- 若一条规则不产生结果，将计算下一条规则。
- 若没有任何规则或 `fallback` 产生结果，也将不产生结果。
